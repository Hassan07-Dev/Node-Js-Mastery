# Node.js & Express.js Mastery — From Scratch to Expert 🚀

A complete, self-paced course to take you from "I know JavaScript" to **interview-ready backend expert** in **5 weeks**.

Stack: **Node.js (LTS) · Express.js · MongoDB + Mongoose · plain JavaScript**

---

## 📌 How to Use This Course

1. **Follow the schedule.** Open [`STUDY-PLAN.md`](STUDY-PLAN.md) — it maps every module, exercise, project, and revision day across 35 days.
2. **Read actively, then build.** Each module ends with **Practice Exercises (+ solutions)** and **Key Interview Points**. Don't skip them — typing the code is where the learning sticks.
3. **Build the projects.** Reading teaches recognition; building teaches recall. The 5 projects are your portfolio and your best interview talking points.
4. **Drill the interview bank** in [`interview-prep/`](interview-prep/) in the final week (and a little each weekend).
5. **Use spaced repetition.** Re-read the "Summary / Cheat Sheet" at the end of each module the day after you first studied it.

> TIP: Keep a terminal open and run every snippet. A concept you've executed beats one you've only read.

## ✅ Prerequisites

Install these before Week 1:

```bash
# Node.js LTS (via nvm is recommended)
node --version    # should be a current LTS, e.g. v20+ or v22+
npm --version

# A code editor (VS Code recommended)
# MongoDB: either install locally OR create a free MongoDB Atlas cluster
# An API client: Postman or the Thunder Client VS Code extension
```

> BEST PRACTICE: Use `nvm` to install and switch Node versions so you can match whatever version a future job requires.
